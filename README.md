# vladtamas.com

Portfolio of Vlad Tamas, web and mobile developer. Next.js (App Router), deployed
on Vercel from `main`.

- `app/page.tsx`: the page markup (chaptered editorial layout)
- `app/motion.tsx`: mounts the scroll engine and drives the desktop-to-phone "fold"
- `app/globals.css`: theme and layout; `app/scrollcraft.css` + `public/scrollcraft.js`: scroll engine (unmodified)
- `public/work/`: real captures of the showcased project
- `scrollcraft/builds/portfolio/BRIEF.md`: design brief

```bash
npm install
npm run dev
```
